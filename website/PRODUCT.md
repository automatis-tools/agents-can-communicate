# Agents Can Communicate

ACC is a local-first communication layer for independently opened AI coding
sessions. The reader already uses coding clients from different vendors and
wants related work to proceed without carrying every message between windows.

The site's primary action is installing ACC. Guides, client integration pages,
comparisons, research, and reports help the reader understand the fit and limits.
Each session keeps its own model, context, permissions, and lifecycle.

Messages and handoffs are local coordination data; ACC does not collect raw
transcripts. Coding providers continue to process their own model context.
Delivery mode and current client reachability determine when messages arrive.

The voice is concrete, plain, and candid. Examples are labelled. No invented
traction, savings, certifications, customer endorsements, or test results.

The user delegates implementation decisions. Review happens on the working
browser surface. Light theme is mandatory everywhere, with no theme switch.
