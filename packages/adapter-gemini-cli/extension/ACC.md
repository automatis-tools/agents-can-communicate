# ACC

ACC (agents-can-communicate) connects this session with the user's other AI agent
sessions on this machine. Its hook context starts with `ACC`. When that context reports
peers, messages or attention, or the user asks to coordinate with other sessions, load the
`acc` skill before you act on it. If no skill tool is available, read
`~/.gemini/extensions/agents-can-communicate/skills/acc/SKILL.md` instead.
