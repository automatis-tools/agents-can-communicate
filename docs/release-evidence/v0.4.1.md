## Published 0.4.0 upgrade

The preflight downloaded published 0.4.0 from npm and verified its registry SHA-1 and
SHA-512 integrity. It installed that package into an isolated home, enrolled Claude Code,
Codex, Gemini CLI and Grok with native delivery off, and explicitly disabled automatic
updates. It created existing intents, a claim, messages and queued/acknowledged receipts.

The published CLI then ran `acc update` against an isolated loopback registry serving
**the unchanged candidate archive above**. The old launcher subsequently reported 0.4.1
and used the new managed generation. Workspace bytes and the complete public snapshot
were preserved. User settings and foreign hooks survived, all four integrations remained
installed, the Grok ownership skill was refreshed, and the explicit auto-update opt-out
remained off. The fixture owners and claim were closed after continuity was verified.
This establishes the actual managed upgrade path; replacing a global npm package alone
does not select a new active managed generation.

Client binaries for the automated upgrade preflight were version-reporting fixtures,
not native capability evidence. Real-client evidence is recorded separately below.
