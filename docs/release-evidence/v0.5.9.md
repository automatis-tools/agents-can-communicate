update wrote and the one it moved off. This is the behaviour this release changes,
measured against the archive that is actually published rather than a fixture. The
private installation was removed afterwards and both caches were empty.

## Limits

This candidate establishes no new native client capability. It runs no new
real-client capture; Claude Code Channel and Codex LocalDaemon keep the evidence and
version minimums recorded for 0.5.8, and their existing limits stand unchanged. See
[Capabilities](../CAPABILITIES.md) and each adapter's `COMPATIBILITY.md`.

The upgrade preflight used client shims, so it certifies the managed upgrade path
and the cache retention rule, not vendor client behaviour. Codex reported its local
delivery service unavailable in that fixture and the install recorded the inbox
fallback, which is the expected result with no vendor service running.
