# ACC v0.11.1 release candidate evidence

This candidate ships the work merged to main after 0.11.0: hooks that read each stored
record once (#300, issue #298), the Claude Code indicator read bound (#293), finding a
client the session start missed (#294) and loading only the modules a command needs
(#296, issue #270). #297 (issue #250) and #299 change tests, scripts and CI only; no
packed file. Store contract 7 and managed-update protocol 2 are unchanged. This is
candidate preparation, not publication.

## Upgrade from published 0.11.0

The previous archive was downloaded from npm. Its SHA-256 matched the published 0.11.0
record: `dea2bb1d94212f35099f4b90e03cf99020ff574def26d4da757c1feda046c521`. Installed in
isolated home, data, project and npm cache directories, with Claude Code 2.1.259 and
Codex 0.135.0 detection shims, its own updater received the exact 0.11.1 archive from a
local registry.

- The automatic-update opt-out set before the update survived it.
- The candidate activated while the old MCP process stayed alive on store contract 7.
- A question sent to that MCP participant before the update was read through the old
  process afterwards with the same id, subject and body, and answered; the reply reached
  the sender.
- `.codex/config.toml` and `.claude/settings.json` kept their bytes. The integration
  refresh wrote ACC's own plugin files for 0.11.1: the Claude Code and Codex plugin
  caches, the local marketplace manifests and `installed_plugins.json`.
- All 376 archive files were installed in the active generation with the same SHA-256.
- After the original npm installation was removed, the stable CLI reported 0.11.1 and
  the stable read-only indicator answered.
- The local registry, MCP process and fixture directories were closed and removed.

The detection shims avoid native service preparation, so this proves package and state
continuity, not native activation.

## Hook cost on real data

#300 was measured on a copy of the maintainer's data home before it merged: a turn
took 0.29–0.41 s in the three largest workspaces, against 0.96–3.80 s on main. See
[its development evidence](unreleased-hook-read-cost.md).

## Limits

No new live capability, captured minimum or store contract is declared. Published
source, artifact and native capture records remain unchanged. These checks do not
establish native activation of a maintainer's running sessions or native behavior on
Windows and Linux; CI covers both platforms' suites. Publication remains a separate
step after the release pull request merges.
