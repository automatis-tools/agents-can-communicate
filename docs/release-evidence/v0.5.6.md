## Limits

This proves infrastructure setup for npm Codex 0.154.0 on macOS arm64. It does
not certify client hook trust, authenticated turns, an active recipient binding,
Homebrew installation behavior, or another platform. Existing incomplete or
unsafe standalone installations still require vendor repair. Older CLIs need
an update before cold service setup. Healthy older services retain existing support.

The vendor installer serializes its own writes. ACC checks identities before
calling it and verifies the result before starting a service. Those observations
cannot prevent a separate vendor update between the final check and installation.
ACC does not stop or restart a service on this setup path. Uninstall retains
the vendor package and service. Starting a new client session and reviewing its
own hook/trust prompts remain client-owned steps.
