## Behavior and compatibility limits

Unanswered questions and requests now require `reply`, not bare `ack`. An answer,
clarification, or refusal satisfies that communication obligation. Historical
acknowledged receipts remain valid. No state migration is required.

An acknowledgement still does not establish accepted scope or executed work.
`finish` still closes the sender's ACC presence without waiting for acceptance.
The five skill templates distinguish authorized continuation, missing scope,
and explicit context-only transfer.

Client executables in the upgrade preflight only reported fixture versions.
They did not execute models or establish native delivery. No new live handoff,
already-loaded skill refresh, or active-client update was captured for this archive.
Existing certification files ship unchanged and retain their original provenance.
The prior synthetic skill exercise and its limits remain in
[the handoff validation record](../internal/evidence/handoff-acceptance/validation.md).
