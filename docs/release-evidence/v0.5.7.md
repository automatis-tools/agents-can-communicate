## Limits

The real exchange used already initialized clients and a temporary installed
candidate plugin. The startup handshake failed before an ordinary prompt hook
bound the Channel. Cold-start delivery remains unverified. This release does not
add capability certifications or guarantee another client version or platform.
An already running Channel can retain its old code until that process restarts.
