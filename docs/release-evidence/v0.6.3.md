## What this release fixes

`acc doctor` prints an adapter's static `deliveryFallback.diagnostic` verbatim. 0.6.2 made
certification evidence apply forward, and three of those sentences still described the gate it
removed, so a client that was delivering was told it is not certified. The upgrade preflight
below reads the line from the installed copy before and after the upgrade:

```
0.6.2  Gemini CLI next-turn delivery is certified only for 0.57.0 on darwin-arm64; other
       or unknown versions keep durable acc inbox access, and live push is unavailable
0.6.3  Gemini CLI next-turn delivery is certified from 0.57.0 onward, on every platform;
       an older client keeps durable acc inbox access, and live push is unavailable
```

Kimi Code and Antigravity CLI carried the same claim and read the same way now. Codex CLI's
diagnostic is unchanged because it names `nativeDelivery.minimumByPlatform`, a contract minimum
that really is per-platform, and Claude Code's names client-side Channels activation and claims
no version.

## Limits

This release changes text that `acc doctor` and `acc install` print, and adds a conformance
case that holds every adapter to it. No capability, capture, receipt or delivery path changes,
no new client behaviour is claimed, and the resolution rule shipped in 0.6.2 is untouched.

The compatibility notes for Kimi Code and Antigravity CLI were corrected in the same change;
they are documentation and are not packed into the archive.
