## Scope and limits

- Native live delivery is opt-in. A detached terminal can leave a loaded Codex thread able to
  consume tokens. Off/uninstall stops new offers and cannot retract already accepted queue items.
- Pending-queue deduplication does not promise exactly-once execution after consumption and
  acknowledgement loss. Native replies, guards and lifecycle capabilities are not newly certified.
- A successfully observed SessionEnd can release a native update hold. Finish, TTL, policy off or
  delivery-binding retirement alone cannot prove that a still-running native process ended;
  missing lifecycle evidence keeps the conservative hold. ACC never stops the vendor daemon.
- The first unmanaged 0.3.1 upgrade requires coordinated client restart. Mixed old/new readers are
  unsupported after decisionChange; native trust/cache activation remains controlled by clients.
- Legacy Codex sandbox settings remain when old ownership cannot be proved. Unrelated and modified
  client configuration/artifacts are preserved.
- Inbox discovery is bounded and read-only; full retrieval advances its own receipt. Superseded
  decisions remain in history and leave automatic current context.
- macOS observations do not certify native Linux behavior. Windows remains outside package support.
  [Capability evidence](../CAPABILITIES.md) retains version/platform boundaries.
- Large-history performance work remains deferred to the next version.

Raw transcripts were not collected by these harnesses. Bounded metadata, synthetic coordination
facts, failed candidates, mutation output and reproduction tools remain in ignored .docs.
